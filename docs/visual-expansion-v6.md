# v1.6 — Visual expansion

背景と敵の繰り返しを減らし、専用の生成素材と戦闘状態に応じて動く機構を増やした更新です。戦闘速度2.25倍、Caravanの実時間120秒、Campaignボス戦の実時間90秒を維持します。

## 新しい敵

| 種類 | 外観と動き | 攻撃 |
|---|---|---|
| Interceptor | 黒い鎌翼、左右から交差する高速編隊、可動フラップ | 2発の高速狙い弾 |
| Bomber | 銅色の幅広機体、変形する翼、低速の揺れ | 加速する3発のミサイル |
| Corvette | 紺と白の長い船体、側面ポッド、停滞してから前進 | 両側の砲口から2発ずつ |
| Sentinel | 紫の中核と花弁装甲、装甲の開閉、浮遊と横移動 | 左右に曲がる菱形の扇状弾 |
| Strider | 銅色の四脚、左右交互に動く脚、地上移動 | 照準を固定して2発・3発を交互に発射 |

道中の繰り返し編隊と置き換え、序盤から出現します。ドローンとランサーも専用素材を使用し、敵は合計14種類。攻撃前の照準固定、供給機、回復アイテム、弾数上限は既存の戦闘システムと共通です。

歩行機・爆撃機・浮遊砲台は分割したテクスチャ面を変形。GPU版は各機体と残骸に独立したジオメトリを持ち、Canvas版は同じ変形座標を使う320px以内・最大24フレームのキャッシュを使用。中央の本体と当たり判定は変形させません。

| ステージ | 生成した景観 | 追加の立体景観 |
|---|---|---|
| 01 小惑星帯 | 破損した環状造船所 | 太陽電池、船体の骨組み、クレーター |
| 02 海上基地 | 双胴の海上空母 | クレーン、連絡橋、電力設備 |
| 03 宇宙要塞 | 塔と光る中枢を持つ都市 | 尖塔、船体の残骸、大型アーチ |
| 04 氷峡谷 | 氷山の観測都市 | 氷のアーチ、クレーター、観測塔 |
| 05 密林遺跡 | 根と滝に覆われた聖域 | 古代祭壇、連絡橋、遺跡アーチ |

地形区画は24種類。絶対距離から連続した曲がりと幅を計算し、施設の密度・位置・縦横比・回転も変えます。GPU版は頂点を変形し、Canvas版は同じ曲がりと幅を区画ごとに適用。外周は固定し、画面端の隙間を抑えます。

新しい大型景観24か所と既存30か所の合計54か所を、一度ずつ配置します。敵・自機・弾より下に描画。煙、航跡、光、クレーン、電力設備、雪、雨、流星がステージの時計で動き、ポーズとリトライに追従します。

## 生成素材と負荷

`app/textures/`の追加WebPは15点。新しい敵5点、ドローンとランサーの更新2点、ステージ専用景観6点、4コマ爆発アトラス、煙です。既存素材と合わせて30点を起動・オフラインキャッシュに含めます。透過画像は背景色に合成して輪郭を確認。敵素材の長辺896px、大型景観1024px、煙768px、爆発アトラス1024pxです。

プロンプトと保存先: [generated-art-v6.json](generated-art-v6.json)。ランサーは生成後に透過背景を編集。迎撃機のみ元のプロンプトの要約を記録しています。

地形のGPU区画は同時10行、24種のテンプレートを必要時に作成。画面外の区画の専用ジオメトリを解放します。CPUキャッシュはステージ切替で破棄し、見えない面を省き、テクスチャの必要範囲だけ描画。関節が動く敵と残骸はそれぞれのジオメトリを終了時に解放します。負荷に応じた解像度・ブルーム・影・天候の調整と、敵弾・破片・残骸・爆炎の上限を維持しています。

## 検証

型チェック・ビルド・30件の自動テストが成功。全6ボスを通常武器の衝突で倒せること、新しい敵の照準固定と攻撃、通常編隊への出現、関節の中央固定とポーズ、地形の連続性と外周、景観の非ループ配置を確認しました。

ChromiumでWebGL 2とCanvas 2Dの両方を確認。720×1280で全6景観、新しい敵の表示・独立した関節ジオメトリ・可動装甲・4コマ爆発・ポーズ時の天候/残骸/カメラ停止・ボス装甲開閉/崩壊・最終クリア・リトライが成功しました。390×844では移動とNOVAの同時タッチ、FOCUS、武器切替、6ステージとボス、戦闘平面との表示位置、適応品質、実時間の120秒/90秒制限、生成素材30点のオフライン再起動を確認。JSエラーとWebGLエラーは0件でした。

v1.5のキャッシュを持つブラウザで更新ボタンを表示し、v1.6へ切り替えて旧キャッシュを削除。30点の素材を読み込み、オフラインでもv1.6で再起動できました。

比較画像は見やすい位置と状態に配置した検証シーンで、自然な全編プレイの録画ではありません。実機WebGPU・iPhoneのフレームレートは未測定です。
