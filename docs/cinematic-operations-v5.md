# v1.5 — Cinematic operations

既存の6ステージと生成した機体・地形素材を使い、背景設備、機体の可動部、戦闘状態、短い無線通信を連動させた更新です。戦闘速度2.25倍、Caravanの実時間120秒、Campaignのボス制限実時間90秒を維持します。

## ステージ

| ステージ | 環境と設備 | 支援演出 |
|---|---|---|
| 01 小惑星帯 | 微粒子、環状基地の回転灯、施設の走査 | 支援艇の通過、LYRAの無線 |
| 02 海上基地 | 潜水艦の広がる航跡、施設の走査 | ヘリ3機の編隊、MIRAの無線 |
| 03 宇宙要塞 | 稼働炉のピストンと噴煙、ゲートの光、レーダー | 支援艇の通過、ORIONの無線 |
| 04 氷峡谷 | 雪、氷壁と大型施設の霧 | 極地ヘリの編隊、LYRAの無線 |
| 05 密林遺跡 | 揺れる樹冠、緑の粒子、滝の霧、遺跡の回転灯 | 支援艇の通過、MIRAの無線 |
| 06 溶岩工場 | 上昇する火の粉、溶鉱炉のピストンと噴煙 | 支援艇の通過、ORIONの無線 |

出撃とボス入場に短いタイトル演出を表示し、道中には区画名と2回の無線通信を用意します。支援機は背景の低い位置を通過し、敵として判定されません。通信は短い日本語のテキストと受信音で、音声セリフはありません。

## 機体と戦闘

- 自機: 移動方向に合わせた旋回とバンク、出撃時の展開、集中射撃とオーバードライブで変わる可動翼・噴射・コアの光、射撃と同期する砲口。
- 敵: 射撃準備の発光、実際に弾を出したときだけ起きる反動と砲口、照準位置に向く地上砲塔、補給機の開閉ハッチ、回転する防衛機の機構、ヒット時の表示。
- ボス: 入場時の翼展開、休止中の装甲開放とコアの発光、射撃反動、フェーズ移行の爆発、撃破後に回転・落下・消失する残骸と7回の二次爆発。破壊済みの翼は残骸に表示しません。
- クリア: 背景と設備が同じ時計で動き、自機が前方へ離脱。最終ボスでは星核回収のメッセージを表示します。

可動部は既存の機体サイズ内に収め、当たり判定や射撃位置を変更しません。新しい姿勢計算はシミュレーションの乱数を消費せず、得点・ダメージ・敵の出現・攻撃ロジックを維持します。

## 実装と負荷

`app/motion.ts`で機体の姿勢、ステージの時計、通信の時間窓を定義。`app/animation-rig.ts`がWebGPU / WebGLの可動部を更新し、Canvas版は同じ姿勢をCPUで描画します。`app/stage-effects.ts`と`app/canvas-effects.ts`が環境演出を受け持ちます。

天候はインスタンシングし、通常42〜100個、低負荷設定34個、視差効果を減らす設定18個に制限。残骸12個、破片1,600個、爆炎・煙48個を上限にし、消えた残骸の独立したマテリアルを解放します。背景の設備は各ステージ5か所。生成した機体の影用ジオメトリを統合し、追加した可動部の描画コストを抑えています。ステージを切り替える際は専用の設備リソースを解放し、共用の形状・素材を誤って破棄しません。

ポーズ中は姿勢・天候・噴射・残骸・カメラ揺れを停止。出撃中と離脱中のポーズも元の姿勢を保ちます。リトライ時は時計、残骸、二次爆発、破片を初期化します。

## 検証

型チェック、ビルド、25件の自動テストで戦闘と追加した時計・姿勢・通信を確認しました。ChromiumのWebGL 2とCanvas 2D、タッチ対応の390×844および720×1280で、6ステージ、集中射撃とオーバードライブ、敵の射撃準備・反動、装甲開閉、崩壊から最終クリアへの遷移を確認。ポーズ中の天候・残骸・カメラの停止と、リトライ時の初期化も通っています。両描画方式でJavaScriptエラー・描画エラーはありませんでした。実機のWebGPU / iPhoneでのフレームレートは未測定です。

ステージ・敵・ボスの比較画像は見やすい位置と状態に配置した検証シーンです。自然な全編プレイの録画ではありません。実際の同時タッチ入力、武器切替、ステージ選択、ポーズ復帰、リトライ、速度2.25倍と実時間120秒・90秒の制限、15枚の生成素材を含むオフライン起動も別に確認しました。旧v1.4のキャッシュから更新ボタンでv1.5へ切り替え、その後のオフライン再起動まで通っています。
