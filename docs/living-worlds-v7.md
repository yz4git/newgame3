# v1.7 — Living worlds

海などの背景を動かし、機体の噴射・着弾・残像を追加した更新です。戦闘・敵14種類・地形24種類・全6ステージ・ゲーム速度2.25倍は既存と共通です。

## 動く背景

| 対象 | 表現 |
|---|---|
| 海 | 3つの合成波、波に追従する法線とUV、異なる方向へ流れる2層の光、広がって消える泡、航跡、船体の小さな揺れ |
| 氷 | 小さい水面の波と光、雪、漂う雲と霧 |
| 密林 | 緑がかった川の流れと光、流れる滝のUVと揺れる水の形、泡、雲、揺れる樹冠 |
| 溶岩 | 小さいうねり、光の脈動、4コマの噴出と飛沫、既存の炉・煙・火の粉 |
| 全ステージ | 生成した雲が多重スクロール・緩やかな横流れ・回転・濃度変化で動く |

`surface-motion.ts`が絶対位置とステージ時計から波形・移動・濃度を計算します。GPU版の水面は1,225頂点。頂点・法線・UVを更新し、2枚の光と最大18枚の泡を重ねます。PERFORMANCE設定では光を1層、泡を最大10枚に削減。画面外の地形とステージ切替時の水面ジオメトリ・テクスチャ複製は解放します。

Canvas版は同じ波形に基づく10帯のテクスチャを描画。帯の両端に共通の参照位置を使い、剪断と拡縮をつないで変形します。光は再利用するパターンで描画し、泡は画面周辺だけを描きます。光と泡も同じ時計で動きます。波の立体的な反射はGPU版の表現です。

## 戦闘アニメーション

自機と飛行する敵のエンジンには、画像生成した噴射炎を使用。噴射の長さ・幅・方向が姿勢と推力に同期します。着弾・NOVA・誘爆・段階変化は4コマのプラズマを追加。オーバードライブと高速移動の残像は、実際の自機位置と旋回の履歴を使用します。

着弾は最大24個、残像は最大6個。GPU版は固定したスプライトを再利用し、Canvas版は同じ状態を描画します。演出は戦闘の乱数・入力・当たり判定に影響しません。動きを減らす設定では残像を生成せず、水面の変位を小さくします。

## 生成素材

追加WebPは8点（約2.2 MB）：海面、泡、光の網、滝、溶岩噴出アトラス、噴射炎、プラズマ着弾アトラス、雲。従来と合わせて38点を起動時とオフラインキャッシュに含めます。透過6点は生成時のアルファを保持し、最長辺896〜1024pxで保存しました。

全プロンプト・保存先・生成方法: [generated-art-v7.json](generated-art-v7.json)。すべて組み込みの画像生成を使用しています。

## 検証

型チェック・ビルド・35件の自動テストが成功。波形と法線の一致、長時間の流れと泡の範囲、ポーズ・リトライでの環境状態、アトラスの全セル、残像の位置履歴・上限・乱数非干渉、新しい敵と全6ボスの通常射撃によるクリアを確認。

ヘッドレスChromiumのWebGL 2とCanvas 2Dで、全6ステージ・ボス、38素材の読み込み、タッチ移動と同時NOVA、武器切替、ポーズ・リトライ、実時間の制限、オフライン再起動を確認。GPU版の水面はスクロール距離を固定しても頂点とUVが変わります。両描画で波・滝・溶岩・着弾・残像の時計、ポーズ時の停止、リトライ時の初期化、動きを減らす設定を確認しました。ブラウザのJavaScriptエラーはありません。

v1.6の30素材を持つキャッシュから更新ボタンでv1.7へ移行し、旧キャッシュの削除、38素材、全6ステージ、オフライン再起動を確認。公開ビルドのキャッシュ対象は現在の46アセットです。
