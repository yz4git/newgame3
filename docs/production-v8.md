# v1.8 — Production finish

全6ステージのボスを専用の生成素材に刷新し、背景の空気感、破壊演出、オリジナルのステレオBGMと効果音、音量設定を追加した更新です。

## グラフィックと動き

ボス6体は本体・左部位・右部位を別々に描画します。展開、部位ごとの微動、砲口の発光、回転する炉、弱点に同期する装甲の開閉、被弾の発光、耐久に応じて残る焼損、部位破壊と崩壊を組み合わせます。透過画像の3つの区画は同じUVと位置関係を使い、部位を壊すと対応する画像と攻撃が消えます。Canvas版も同じ切り出し・角度・損傷量を使用します。

宇宙には星雲、氷にはオーロラ、海・密林・溶岩には光の帯を重ねます。流れ、横揺れ、濃度、回転をステージ時計に同期させ、通常描画では平面の頂点も小さく変形します。v1.7の動く海、川、滝、溶岩、雲、雪、設備を継続して使用します。

爆発と部位破壊には4種の金属片、NOVA・誘爆・ボス撃破には生成した透過の衝撃波を使用します。破片は最大48個、衝撃波は最大4個。PERFORMANCE設定とCanvas版の破片表示は24個までです。環境の追加レイヤーは2枚、PERFORMANCE設定では1枚にします。ポーズ中は停止し、ステージ開始・リトライ時に初期化します。動きを減らす設定では追加の破片・衝撃波を消し、環境の揺れを弱めます。戦闘の乱数を使いません。

追加素材は12点、4,665,344バイト。ボス6体、衝撃波、破片アトラス、焼損、星雲、オーロラ、光の帯です。すべて組み込みの画像生成を使用し、実際のアルファを持つWebPを組み込みました。合計50素材です。全プロンプトと保存先は [generated-art-v8.json](generated-art-v8.json) に記録しています。

## サウンド

8曲を新規作曲し、オリジナルの音色でステレオ音源を制作しました。外部の楽曲やサンプルは使用していません。

| シーン | 曲 | BPM |
|---|---|---:|
| 小惑星帯 | Orbital Pulse | 136 |
| 海上基地 | Blue Squadron | 142 |
| 宇宙要塞 | Citadel Circuit | 144 |
| 氷峡谷 | Prismatic Flight | 132 |
| 密林遺跡 | Emerald Mechanism | 140 |
| 溶岩工場 | Foundry Pressure | 148 |
| タイトル・リザルト | The Last Signal | 96 |
| ボス | Reactor Pursuit | 156 |

ベース、リード、プラック、ベル、パッド、複数の打楽器、ステレオのディレイを合成し、旋律・音色・リズムをシーンごとに変えています。ループの終わりから冒頭へ残響を回し、マスター処理後に44.1 kHz / 128 kbpsのMP3へ変換します。8曲合計3,353,015バイト。各曲は20〜29秒のループです。

BGMは必要な曲を読み込み、1秒でクロスフェードします。ポーズ時に再生位置を保存し、復帰時はその位置から再開します。音声はスタートや試聴などの操作で有効になります。全体・BGM・効果音の音量とミュートを端末に保存します。

効果音は17系統。3武器、敵弾、着弾、爆発、重い爆発、NOVA、ボス崩壊、被弾、アイテム、ロック、無線、段階変化、警告、メニュー、クリア音を独自合成します。位置に応じた左右の定位、短いステレオ残響、重要な攻撃時にBGMを下げるミックス、コンプレッサーを使用します。発音は24ボイスまで、連射音には間隔制限、混雑時には重要な効果音を優先します。

再生成にはnumpy・scipy・ffmpegを使用します。ゲーム実行時には不要です。

```bash
python scripts/compose-score.py
# 曲を指定して再生成
python scripts/compose-score.py boss
# ファイル完全性・デコード・音量・ループ境界の検査
python scripts/check-score.py
```

音源一覧: [soundtrack-v8.json](soundtrack-v8.json)。波形の検査結果: [audio-metrics-v8.json](audio-metrics-v8.json)。

## 検証範囲

型チェック・公開用ビルド・40件の自動テストが成功しました。追加テストは、モバイルで使用する3つのサンプルレートでの効果音の有限値・クリップ・発音境界、音量と定位の範囲、破片と衝撃波の上限・ポーズ・初期化・乱数非干渉、長時間の環境位置、ボス損傷量と部位の角度を検証します。

ヘッドレスChromiumのWebGL 2とCanvas 2Dで、全6ステージ・全6ボス・50素材・部位破壊・焼損・NOVA・関節・崩壊・最終クリア・ポーズ・リトライ・動きを減らす設定を確認しました。通常描画では機体ごとの変形ジオメトリ、地上目標の投影、PERFORMANCE設定への切り替えも確認しました。

スマホサイズでタッチ移動と同時NOVA、武器切替、ステージ選択、ポーズ・リトライ、2.25倍のゲーム速度、実時間の120秒 / 90秒制限、ズーム固定を確認しました。50画像と8音源を持つオフライン起動・再生、v1.7から更新ボタンによるv1.8への移行と旧キャッシュ削除も成功しました。公開用アセットは66ファイル、約24.4 MBです。

音声はブラウザのAudioContextによる8曲すべてのステレオデコード、出力波形、操作による解除、ミュート、音量保存、ボス曲への切り替え、ポーズ位置の保存と復帰、24ボイス上限と優先順位、モーダル内のキー操作を確認しました。MP3のピークは0.336〜0.474、ループ両端のサンプル差は0.0019〜0.0186で、非有限値やクリップはありません。直接聴いて行う音色・聴感の評価は、この実行環境では実施していません。

[6体の比較画面](guardians-v8.webp) と [音付きプレビュー](production-v8.mp4) は描画確認用に配置したシーンです。動画は4秒・480×854px・12 fpsで、ゲームの音源と効果音からレンダリングした音を使用しています。全編の自然なプレイ録画ではありません。実機のWebGPU / iPhoneのフレームレートは未測定です。
