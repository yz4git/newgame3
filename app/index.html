HOW TO PLAY

移動 / 自動射撃画面のどこからでも指をドラッグ。機体が同じ方向へ動きます。PCは矢印キー / WASD。

WEAPON / 武器切替WIDE：広範囲　LASER：正面火力・貫通
HOMING：敵を追尾。FOCUSで前方の敵をロックし、火力と得点を伸ばせます。補給機を倒して4段階強化。

NOVA / 緊急攻撃敵弾を消し、全体攻撃＋一時無敵。ゲージ満タンならボムを消費せず、約2.7秒間火力1.35倍。

FOCUS / 精密移動押し続けると低速移動。WIDEは集中、LASERは火力・貫通、HOMINGはロックオンが強化されます。白い小さな円が自機の当たり判定です。

スコアの伸ばし方素早い連続撃破で最大8倍。かすりでも連鎖を維持。接近撃破は1.5倍、ロック撃破は1.25倍。メダルは逃さず集めると最大5段階に成長します。

REACTIVE BATTLEFIELD / 戦場変異施設を破壊すると戦場に残骸が流れ込み、遮蔽物が敵弾を防ぎます。機体は遮蔽物に触れると安全に押し戻され、敵編隊も迂回します。施設を取り逃がすと危険な障害物が出現。赤い予告の後に有効になり、射撃で破壊できます。撃破した障害物や遮った敵弾でスコアアップ。

STAGED DESTRUCTION / 施設の段階損傷施設の耐久が約2/3になると装甲が割れ、自身の発射弾が消えます。約1/3で炉心が露出し、周囲に小爆発。完全破壊すると残骸が連続爆発し、周囲への誘爆や敵の射撃停止につながります。

BATTLEFIELD CHAIN / 戦場連鎖CAMPAIGNの各ステージに2つの戦略設備が登場します。金色の目標を撃破すると連鎖爆発・敵弾消し・射撃停止。2つとも壊すとボスの部位耐久が15%低下します。逃すと増援が発生し、しばらく敵撃破スコア+25%ですが、ボス部位耐久が10%増加します。

機体タイプ / BOSS RUSHSTRIKERは標準、FALCONは高速・高火力で低耐久、BULWARKは高耐久で低速・低火力。BOSS RUSHは6体の大型ボスとの連戦で、武器レベル3から開始します。

REACTOR BREAK / 誘爆琥珀色の炉を持つ大型巡洋艦を倒すと、周囲の敵にダメージ＋敵弾を得点へ変換。近くで倒すほど爆風が広がります。

狙い弾とボス攻略ピンクの予告線が狙い弾の進路。狙いが固定されたら横へ移動。ボスの砲台を壊すと、その砲台の弾が消えます。CORE EXPOSED中は本体へのダメージ1.6倍。作戦モードのボス戦は90秒制限。早く撃破するとタイムボーナス。
